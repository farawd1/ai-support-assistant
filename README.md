# Support Studio — Jev + DeepSeek

Локальный MVP помощника оператора: обращения, классификация, приоритет, поиск по статьям, ответ с цитатами, принятие/редактирование/эскалация, dashboard. Интерфейс на русском. Данные сохраняются в SQLite.

## Запуск

Python 3.12+. В этом workspace уже создана `.venv`.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000. По умолчанию `AI_MODE=demo`: детерминированные правила и шаблон вместо AI-вызовов, без затрат. Стартовые статьи описывают вымышленную компанию. Не использовать их как реальные бизнес-политики.

На этом Mac доступен Python по пути `/Users/adilkhanmeirkhan/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`, если системный `python3` отсутствует.

## Реальные модели

Скопировать `.env.example` в `.env`, заполнить локально:

```dotenv
AI_MODE=live
TYPESAFE_API_KEY=your-key
DEEPSEEK_API_KEY=your-key
JEV_MODEL=jev-1.13.0
DEEPSEEK_MODEL=deepseek-flash
```

Перезапустить сервер. `.env` исключён из Git. Ключи не передаются браузеру. Не присылайте их в чат. Ключи создаются в кабинетах [TypeSafe](https://console.typesafe.ai/) и [DeepSeek](https://platform.deepseek.com/). Live-режим отправляет текст обращения и вопросы классификации TypeSafe, а текст обращения и выбранные статьи — DeepSeek; для теста использовать синтетические данные.

Jev: topic Choice + security/money/blocked Noul в одном вызове; приоритет вычисляет код. Пороги .65 и .7 предварительные, требуют калибровки на RU/KK. Английский — основной язык обучения Jev.

DeepSeek: JSON Output, thinking disabled, проверка Pydantic, обязательные источники для draft. Проверяется ID документа и точное наличие цитаты в тексте. Это не проверка семантической поддержки каждого утверждения. Нет данных в базе → уточнение; P0 → эскалация по правилу без генерации.


6 тестов: полный сценарий и метрики редактирования, неизвестный запрос и безопасность, индексация статьи, выдуманные цитаты, mocked live-контракты, видимая ошибка провайдера. Реальные оплачиваемые вызовы не выполнялись; качество моделей на обращениях не измерено.

## Границы первого MVP

- SQLite FTS5/BM25 и предпочтение темы. Нет embeddings, семантического поиска и русского стемминга; качество поиска на перефразировках ограничено.
- REST: создание ждёт анализа. Нет постоянной очереди worker/SSE; прерванные запросы после перезапуска помечаются failed и могут быть повторены.
- Локальная single-user версия без аутентификации и изоляции компаний. Запускать на `127.0.0.1`; не публиковать эту версию как сервис для реальных клиентов.
- Поддерживаются текстовые статьи через форму; нет импорта PDF/CRM/Telegram.
- Версия статьи сейчас 1; полноценного редактирования/версий пока нет. В черновике сохраняется снимок найденных документов.
- Dashboard показывает все обращения, без фильтра периода. Действия оператора хранятся в журнале; повторное действие обновляет текущий итог без увеличения числа рассмотренных обращений.
- Принять ответ сохраняет решение, но не отправляет сообщение клиенту.
- Таймаут и до 3 попыток на временные ошибки API. Нет расчёта стоимости и автоматического failover.
